# Project Docs

This folder contains user-facing documentation and design artifacts for Al‑amer Mall.

- User stories (requirements collection)
- Draw.io low-fidelity design (`Alamer Mall - LFD.drawio`)

## How to open the low‑fidelity design

You can open the `.drawio` file using:

- The Draw.io desktop app
- The browser editor at https://app.diagrams.net (File → Open from your device)

## Files

- `Alamer Mall - Requirements Collection 2.docx`: User stories and requirements.
- `Alamer Mall - LFD.drawio`: Low-fidelity wireframes in Draw.io format.
